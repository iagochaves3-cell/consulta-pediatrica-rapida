# Consulta Pediátrica Rápida

Roteiro web, responsivo e sem dependências para apoiar a formulação de anamnese e exame físico pediátricos em pronto atendimento.

## Uso

Abra `index.html` no navegador. A idade adapta os lembretes por faixa etária, os campos organizam a consulta e o botão **Gerar resumo** prepara uma síntese para revisão.

Os dados ficam apenas na página e não são enviados a nenhum servidor. A ferramenta é um apoio à consulta e não substitui julgamento clínico ou protocolos locais.
